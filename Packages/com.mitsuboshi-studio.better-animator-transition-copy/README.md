# Better Animator Transition Copy

Animator Transitionの条件をまとめてコピー・貼り付けします。 正式版 **1.0.0**。Unity 2022.3向けのEditor専用パッケージです。

## VCCに追加

### [▶ クリックしてVCCを開く](https://rinya-mitsuki.github.io/vpm-repository/add.html)

ブラウザーの確認で「開く」を選び、VCCでリポジトリの追加を確定してください。登録済みなら再登録は不要です。Manage Projectから **Better Animator Transition Copy** を追加・更新できます。試験版表示の設定は不要です。

VRChat SDK Base 3.10.4以上・4未満が必要です。VCCの公式VRChatリポジトリから解決されます。検証には3.10.4を使用しました。

## 旧版からの移行

既存の `BetterAnimatorTransitionCopy_2022_3_v1_3.cs`（同じクラスを定義する別版を含む）と対応する `.meta` をプロジェクト外へ退避してから導入してください。共有Editorフォルダー全体を削除しないでください。旧版との二重導入を避けてください。

## 使い方

Animatorの右クリックメニュー Copy/Paste Transition Collection または Ctrl+C / Ctrl+V を使用します。コピー対象は条件で、貼り付け先の設定を維持し、不足する遷移は貼り付け先を雛形に作成します。Unity内部APIとHarmonyに依存します。Unity 2022.3.22f1向けです。
